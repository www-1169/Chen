CASE STUDY / 01

Star Assault: Galactic Defense

01 / OVERVIEW

Genre: Space Shooter Platform: Browser Engine: Vanilla JS + Canvas

Star Assault（星际突袭：银河防线）是一款基于浏览器的 Canvas 2D 太空生存射击游戏。玩家驾驶飞船在不断升级的波次中生存，收集稀有升级，最终迎战 Boss Void Titan。

02 / GAMEPLAY

核心循环简洁而具有深度：移动 → 射击 → 躲避 → 升级。随着 Wave 推进，敌人组合与行为模式逐渐复杂，迫使玩家不断调整策略。

BOSS

Wave-based 难度递进：每波敌人密度与行为组合递增，Boss 波次为当前峰值。

03 / SYSTEMS

Enemy AI

多种敌人类型具备不同移动轨迹与攻击方式，形成动态威胁场。

Wave Engine

可配置的波次表控制敌人类型、数量与出现节奏，支持持续扩展。

Boss Void Titan

多阶段 Boss 战：血量阈值触发行为切换，考验走位与输出节奏。

Upgrade Rarity

Common · Rare · Epic · Legendary 四级稀有度，掉落与强度分层。
