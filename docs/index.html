CASE STUDY / 01

Star Assault: Engineered Interactive System

01 / PROBLEM

How do you build a complete browser game without engines or heavy frameworks? The goal was to create a responsive, performant interactive system that runs on desktop and mobile, using only native web technologies.

02 / DESIGN DECISION

The design prioritizes a tight core loop — move, shoot, dodge, upgrade — with emergent complexity from enemy combinations and a multi-stage Boss encounter. Wave difficulty is authored through data, not hard-coded behavior.

03 / ARCHITECTURE

Six specialized subsystems built on top of the core architecture.

04 / IMPLEMENTATION

Game Loop

requestAnimationFrame-driven update/render cycle with deterministic delta time.

Wave System

Data-driven wave tables control enemy type, count and spawn rhythm for scalability.

Boss System

Multi-phase Boss with health-threshold behavior switches and pattern attacks.

Upgrade System

Common · Rare · Epic · Legendary rarity tiers with probability-weighted drops.

Audio System

Web Audio API generates real-time synthesis for shooting, explosions and power-ups.

Storage System

localStorage persists leaderboard, settings and achievements across sessions.

05 / RESULT

A fully playable browser game with keyboard, mouse and touch input, no installation required. It demonstrates systems thinking, state management and performance-aware rendering in a constrained environment.
